# tfile

C11과 ncursesw로 구현한 Linux/WSL용 터미널 파일 관리자입니다. 터미널 안에서 파일을 탐색하고 내용을 미리 보며, 이름 검색과 생성·복사·이동·삭제를 수행할 수 있습니다. 키보드와 마우스를 함께 지원합니다.

## Overview

실행할 때 지정한 디렉터리 또는 현재 작업 디렉터리를 엽니다. 왼쪽 목록에서 항목을 선택하면 오른쪽에 메타데이터와 텍스트 미리보기가 표시됩니다. 파일 작업은 팝업에서 입력·확인하며, 결과와 오류는 하단 상태 영역에 표시됩니다.

파일 접근은 로컬 파일시스템을 대상으로 합니다. 데이터베이스, 외부 API, 네트워크 서비스, 계정이나 API 키를 사용하지 않습니다.

## Features

- **탐색:** 디렉터리 열기, 상위 디렉터리, 이전·다음 방문 위치, 숨김 파일 표시, 명시적 새로고침.
- **목록:** 이름 우선 열 구성, 폭에 따른 종류·크기·수정일 표시, 이름·크기·수정일·종류별 오름차순/내림차순 정렬. 선택은 색상 외에도 `>`와 굵기로 표시합니다.
- **미리보기:** 일반 텍스트의 페이지 단위 읽기와 키보드·휠 스크롤, 종류·크기·수정일·권한, 링크 대상, 바이너리 및 읽기 오류 안내. 디렉터리 내부의 총용량은 계산하지 않습니다.
- **이름 검색:** 현재 디렉터리 아래에서 숨김 항목을 포함한 부분 문자열 검색, 진행 표시, 취소 후 수집 결과 확인, 상대 경로로 결과 구분, 결과 위치 열기.
- **파일 작업:** 파일·디렉터리 생성, 복사, 같은 파일시스템 내 이동·이름 변경, 확인 후 삭제. 복사·이동은 원본과 목적지를 선택기로 지정할 수 있습니다.
- **진행과 취소:** 복사·삭제의 현재 경로와 완료 항목 수, 복사 바이트 표시. 취소·부분 완료·오류·작업 후 목록 갱신 실패를 구분합니다.
- **안전한 문자열 표시:** 한글 입력, 셀 폭을 고려한 생략, 제어문자·잘못된 UTF-8 바이트의 이스케이프 표시와 실제 작업 이름의 원본 바이트 보존.

상·하단 명령/안내 바는 중립색 배경과 굵은 키 표기로 본문과 구분합니다. 하단 안내는 클릭 버튼이 아니며, 상태 결과는 바로 위의 별도 줄에 표시됩니다. 패널 제목은 굵게, 개수·정렬과 보조 열은 중립색으로 표시하고 파일 종류 색상은 일반 행의 이름에 적용합니다. 선택 행은 전체 강조와 `>`를 유지합니다. 작은 화면에서는 상단 명령명을 F키로 축약하며 F9 전체 메뉴를 사용할 수 있습니다. 단색에서는 바의 반전과 열 제목의 밑줄을 사용합니다. 팝업을 열면 배경 강조와 메인 안내를 낮추고 팝업별 안내를 표시하며, 닫으면 이전 화면 속성을 복원합니다.

## Architecture

의존 방향은 **UI → core → platform**입니다. 공통 모델은 어느 레이어도 참조하지 않습니다. UI에는 ncurses 입력·렌더링·팝업이 있고, core에는 터미널과 독립적인 상태·정책이 있으며, 실제 파일시스템 호출은 platform에 있습니다.

```mermaid
flowchart LR
    User[키보드 / 마우스] --> UI[UI: 입력 루프·팝업·컨트롤러]
    UI --> Core[core: 탐색·정렬·검색·파일 작업·미리보기]
    Core --> Platform[platform: POSIX 구현]
    Platform --> FS[로컬 파일시스템]
    Platform -- 데이터와 Result --> Core
    Core -- 결과·페이지·진행 콜백 --> UI
```

- **진입점:** `src/ui/main.c`의 `main()`이 로캘, `AppState`, ncurses와 마우스를 초기화하고 그리기·입력 루프를 실행합니다. 종료 시 미리보기와 앱 상태를 해제합니다.
- **상태:** `AppState`는 경로·파일 목록·정렬·옵션·방문 기록을 소유합니다. `UiContext`는 목록/미리보기 초점·선택·스크롤·미리보기 세션·상태 문구·모달 깊이를 관리합니다.
- **탐색:** UI 컨트롤러가 `app_navigate()`/`app_refresh()`를 호출합니다. core가 경로를 해석하고 새 목록을 얻은 뒤 성공한 경우에만 기존 상태를 교체합니다.
- **검색과 파일 작업:** core/platform의 동기 작업이 콜백으로 진행 상태를 전달합니다. UI 콜백이 입력을 확인하고 취소 여부를 반환합니다. 작업 스레드나 별도 서버는 없습니다.
- **미리보기:** UI 준비 단계에서 core의 `PreviewSession`에 필요한 페이지를 요청하고 렌더링은 준비된 데이터를 사용합니다. 팝업의 배경 초점 전환도 준비된 데이터만 다시 그립니다.

## Tech Stack

| 구성 | 역할 |
| --- | --- |
| C11 | 프로그램과 네이티브 회귀 테스트 |
| ncursesw | 터미널 화면, 넓은 문자, 키보드·마우스 입력 |
| Linux/POSIX 파일 API | 경로·디렉터리·파일 읽기/쓰기, 권한, 단조 시계 |
| Make와 C 컴파일러 | 실행 파일과 테스트 빌드 |
| Python 3 표준 라이브러리 | 임시 파일·권한·PTY 통합 테스트 |

Python은 테스트에 사용하며 프로그램 실행에는 필요하지 않습니다. Python/Node 패키지 매니페스트나 별도 패키지 설치 단계는 없습니다.

## Getting Started

### Prerequisites

- Linux 또는 WSL. 현재 플랫폼 소스는 `posix` 하나이며 Linux의 `renameat2(RENAME_NOREPLACE)` 등을 사용합니다.
- C11 컴파일러, `make`, ncursesw 헤더와 링크 가능한 라이브러리.
- UTF-8 로캘과 ncurses가 인식하는 터미널 환경. 마우스 조작에는 터미널의 마우스 이벤트 지원이 필요합니다.
- 최소 **50열 × 9행**, 권장 **100열 × 24행 이상**. 특수 폰트나 Nerd Font는 필요하지 않습니다.

### Installation

위 도구와 라이브러리가 준비된 환경에서 저장소를 내려받은 후 프로젝트 루트에서 빌드합니다.

```sh
make
```

루트에 `tfile` 실행 파일이 생성됩니다. Makefile에는 시스템 설치용 `install` 대상이 없습니다.

### Running

```sh
./tfile                      # 현재 작업 디렉터리
./tfile /path/to/directory    # 지정한 디렉터리
```

위 경로는 사용할 실제 디렉터리로 바꿉니다. 위치 인자는 하나까지 받으며 별도 명령행 옵션은 없습니다.

## Usage

### 탐색과 미리보기

1. 목록에서 파일을 클릭하거나 방향키로 선택합니다. 오른쪽에서 정보와 본문을 확인합니다. 파일의 `Enter`/Open은 숨겨진 미리보기를 켜고 미리보기에 초점을 옮깁니다. 같은 파일의 준비된 미리보기는 스크롤과 캐시를 유지합니다.
2. 디렉터리를 더블클릭하거나 `Enter`로 엽니다. **Parent** 또는 `Backspace`로 상위 디렉터리에 갑니다.
3. 왼쪽 목록 위의 휠은 선택을 이동하고, 오른쪽 미리보기 위의 휠은 내용을 스크롤합니다.
4. `Tab`/`Shift+Tab` 또는 패널 내부 클릭으로 목록과 미리보기 초점을 바꿉니다. 활성 제목의 `*`와 선명한 테두리, 하단 안내가 입력 대상을 표시합니다. 미리보기가 숨겨져 있으면 목록만 초점을 받습니다.
5. 미리보기 초점에서는 `↑`/`↓`(또는 `k`/`j`)로 한 행, `PgUp`/`PgDn`으로 표시 높이만큼 이동하고 `Home`으로 처음에 돌아갑니다. `Esc`는 목록으로 돌아갑니다. 파일 선택과 목록 스크롤은 유지됩니다. F키 파일 작업은 계속 `>`로 표시된 선택 항목을 대상으로 합니다.
6. **F7 Options**에서 숨김 표시·미리보기·휠 이동량·정렬을 바꿉니다. 창을 유지한 채 즉시 적용하며 변경한 옵션의 초점과 옵션 목록 스크롤도 유지합니다. Esc/Done은 적용된 값을 되돌리지 않고 닫습니다. 숨김 전환 중 목록 조회가 실패하면 이전 설정·목록과 오류를 유지합니다.

평상시 상태줄의 `Shown`은 숨김 필터를 적용한 현재 목록의 항목 수이며, 디렉터리 전체 항목 수나 현재 화면에 들어오는 행 수가 아닙니다. `Hidden: on/off`는 숨김 파일 표시 설정입니다. 기존 작업 결과·오류·취소·누락 메시지가 있으면 요약보다 우선하며 자동으로 지우지 않습니다. 이 표시는 추가 파일 조회 없이 보유한 목록을 사용합니다. 빈 목록에는 `No visible items`를 표시하고, 숨김 표시가 꺼져 있으면 F7 설정을 안내합니다. 실제 디렉터리가 비었는지 별도로 조회하지 않습니다. 목록의 위나 아래에 화면 밖 항목이 있을 때만 아래 테두리에 `Shown 시작-끝/표시 항목 수`를 표시하며, 폭이 부족하면 `Top`/`End`와 `^ more`/`v more`로 줄입니다.

**F7 Options → Show preview panel**에서 미리보기를 숨기면 목록이 전체 폭을 사용합니다. 토글은 선택과 목록 스크롤을 유지하며, 미리보기 reader는 기존 정책대로 숨길 때 해제하고 다시 표시할 때 준비합니다. 넓은 화면(120열 이상)의 상단 명령 바는 그룹 사이 간격을 넓히며, 좁은 화면의 F키 축약과 F9 메뉴 접근은 유지합니다.

목록의 크기는 읽기 쉬운 단위로 오른쪽 정렬합니다. 디렉터리 크기는 `-`이며 내부 총용량을 뜻하지 않습니다. 정렬 설명은 공간이 있으면 `Name ascending`처럼 표시하고 좁으면 `Name+`, `Time-`로 줄입니다(`+`: 오름차순, `-`: 내림차순). Location의 긴 경로는 끝부분을 우선 표시합니다.

미리보기는 이름, 종류·크기·권한, 수정일 뒤에 본문이 시작됩니다. 디렉터리는 `Directory | Mode 0755`처럼 표시하며 크기 자리표시자를 넣지 않습니다. 폭이 좁으면 보조 정보를 줄입니다. 스크롤이 필요할 때만 위치 안내를, 스크롤 후 마지막 화면에서는 `End`를 표시합니다.

### 이름 검색

- `F3` 또는 `/`로 작은 중앙 입력창을 엽니다. 검색어를 입력하고 `Enter` 또는 **Search**를 누릅니다. `Tab`/`Shift+Tab`으로 입력란·Search·Cancel 초점을 옮깁니다. 입력 단계의 `Esc`, **Cancel**, **x**는 창을 닫습니다.
- 검색을 시작하면 같은 창이 진행·결과용 크기로 확장됩니다. 결과 수에 따라 크기를 다시 바꾸지 않습니다.
- 검색 중 **Cancel**, `Esc` 또는 `Enter`는 검색을 중단하고 **이미 수집한 결과를 유지**합니다. **x**는 중단 후 창까지 닫습니다. 리사이즈도 검색을 중단하고 창을 닫습니다.
- 결과 단계에서 방향키·휠로 선택하고 `Enter`/**Open** 또는 더블클릭으로 엽니다. 파일 결과는 부모 디렉터리에서 정확한 항목을 선택하며, 숨김 결과라면 숨김 표시를 켭니다.
- 결과의 **Search**, `/`, `F3`는 기존 검색어가 들어 있는 작은 입력창으로 돌아갑니다. `Home`/`End`, 방향키, Delete/Backspace로 편집할 수 있습니다. 결과 단계의 `Esc`/**x**는 닫기입니다.

팝업이 열리면 뒤쪽 메뉴·목록·미리보기·테두리와 파일 종류 색상을 모두 낮추고 메인 단축키 안내를 숨깁니다. 팝업을 단순히 닫으면 원래 패널 초점·선택·미리보기 위치를 유지합니다. 미리보기를 끈 경우에는 목록 초점으로 돌아갑니다. 일반적인 닫기 메시지는 추가하지 않으며, 기존 작업 결과나 검색 취소·누락·오류 상태는 남깁니다.

### 팝업과 도움말

모든 팝업은 메인 화면과 다른 중립 배경, 선명한 테두리, 낮은 채도의 제목줄을 사용합니다. 굵은 제목과 오른쪽 위의 `[ x ]`는 고정되며, 하단 두 행은 구분선 안의 안내와 버튼 영역입니다. 현재 입력/선택 초점은 강조색과 굵기로, 사용할 수 없는 버튼은 낮은 강조로 표시합니다. 8색 환경에서는 중립적인 대비를, 단색 환경에서는 테두리 굵기·제목과 초점의 반전을 사용합니다. 트루컬러나 특수 폰트는 필요하지 않습니다.

`F1` 도움말은 짧은 시작 안내 다음에 탐색·파일 작업·검색·미리보기·옵션 순서로 구성됩니다. 창 너비는 최대 78열입니다. 공간이 있으면 단축키와 설명을 열로 정렬하고, 좁으면 설명을 들여쓴 다음 줄로 넘깁니다. 본문만 스크롤하고 제목과 하단 안내는 고정됩니다.

하단의 `Lines 1-18/90`은 **줄바꿈 후 표시 줄 중 현재 보이는 범위와 전체 줄 수**를 뜻하며 페이지 번호가 아닙니다. `Top`/`End`는 처음/끝, `^ more`/`v more`는 위/아래에 내용이 남았음을 뜻합니다. 휠·방향키로 한 줄, PgUp/PgDn으로 한 화면씩 이동하고 Home/End로 처음/끝에 갑니다. Esc, x, F1, q, F10으로 도움말을 닫을 수 있습니다. 리사이즈 시에는 기존 정책대로 닫습니다.

배경을 낮추거나 복원하는 과정에서는 준비된 데이터와 셀 속성만 사용하며, 파일 목록 재조회·미리보기 본문 재읽기를 수행하지 않습니다.

### 파일 작업과 주의 사항

이름 변경·경로 입력을 포함한 입력창은 빈 값이나 출력 바이트 길이 초과를 창 안에 표시하고 값과 편집 위치를 유지합니다. 경고 후 바로 수정할 수 있으며 원본 이름의 제어문자·잘못된 바이트 보존 정책도 유지합니다.

- **F2 New:** 파일/디렉터리 종류와 이름을 입력합니다. 기존 이름과 충돌하면 수정할 수 있도록 창을 유지합니다.
- **F5 Copy / F6 Move:** 원본, 대상 디렉터리, 이름을 확인하고 **Copy now / Move now**로 실행합니다. 같은 디렉터리에서 이름을 바꾸면 이름 변경입니다.
- **F8 Delete:** 기본 선택은 **Cancel**입니다. 긴 이름은 확인창의 페이지 버튼 또는 PgUp/PgDn으로 확인할 수 있습니다.

**삭제는 휴지통을 거치지 않으며 실행 취소할 수 없습니다.** 디렉터리 삭제는 자식도 삭제합니다. 복사·이동은 기존 대상을 덮어쓰지 않습니다. 이동은 같은 파일시스템 안에서만 지원합니다.

복사·삭제 진행 창에서 Cancel/Esc/Enter/x로 취소할 수 있고 리사이즈도 취소를 요청합니다. **취소는 롤백이 아닙니다.** 복사한 파일·미완성 대상은 남고 삭제한 항목은 복원되지 않습니다. 작업 결과와 그 뒤 목록 갱신 실패는 별도로 표시합니다.

## Configuration

사용자 설정 파일이나 앱 전용 환경 변수를 읽지 않습니다. Options 설정은 현재 실행에만 적용됩니다. 기본값은 숨김 파일 표시 켜짐, 미리보기 켜짐, 휠 1행, 이름 오름차순입니다. 휠 이동량은 1·3·5행 중 선택합니다.

로캘은 `setlocale(LC_ALL, "")`로 실행 환경을 따릅니다. ncurses는 `TERM`에 해당하는 터미널 정의를 사용하고, 수정일 표시는 `localtime()`을 사용합니다. 파일 생성·복사 권한에는 실행 환경의 `umask`가 적용됩니다.

빌드에서는 Makefile의 `CC`, `CFLAGS`, `CPPFLAGS`, `LDLIBS`를 사용할 수 있습니다. `PLATFORM` 기본값은 `posix`이고 다른 백엔드는 제공하지 않습니다. 테스트 스크립트의 `TFILE_BINARY`, `TFILE_*_TEST` 등은 테스트 실행 파일을 바꾸는 용도이며 앱 설정이 아닙니다. 파이프 동기화 테스트의 `TFILE_GATE_EVENT`/`TFILE_GATE_COMMAND`도 테스트 전용입니다.

## Testing

테스트에는 Python 3와 빌드 도구가 필요합니다. 프로젝트 루트에서 실행합니다.

```sh
make check-core  # core·POSIX·안전성·검색·정렬·의존성 검사
make check       # 위 검사 + UI·미리보기·실제 PTY 통합 검사
make clean       # 빌드한 실행 파일과 테스트 바이너리 삭제
```

- C 테스트는 정렬의 8가지 조합, 선택 식별, 탐색 상태, 검색 한도·취소·누락·오류, 파일 작업의 실패·부분 완료, 페이지 캐시와 EOF를 검사합니다.
- reader·목록 함수의 링크 래퍼는 동일 화면·정렬·팝업 초점 변경에서 추가 파일 열기와 본문 읽기, 불필요한 목록 조회가 없는지 계수합니다.
- ncurses 셀 검사는 256색·8색·단색에서 팝업 배경·제목·테두리·하단·초점·비활성 속성과 한글 셀 보존, 종료 후 원래 색상 복원을 확인합니다. 도움말 PTY 검사는 50×9·80×24·160×32에서 줄바꿈된 전체 내용을 읽으며 표시 줄 범위와 제목/하단 경계를 검사합니다.
- Python PTY 검사는 키보드·마우스, 50×9와 더 큰 화면, 유니코드와 제어문자 이름, 팝업 테두리·버튼·리사이즈·모달 입력 차단을 확인합니다. 검색과 파일 작업 취소는 테스트 전용 파이프로 실제 진행 콜백을 동기화합니다.
- `tests/navigation_pty.py`는 표시 항목 집계·숨김 전환, 목록 범위, 미리보기 토글 후 선택·스크롤, 빈 목록, 한글 이름, 상태 메시지 우선순위와 리사이즈를 검사합니다.
- `tests/keyboard_ui_test`와 `tests/keyboard_pty.py`는 일반 입력 오류·편집 위치·원본 바이트, 옵션 초점·실패 복구, 패널 키보드/마우스 초점, 미리보기 페이지 이동과 팝업 복원을 확인합니다. `tests/preview_test`는 같은 파일 Enter와 초점 전환의 reader·본문 읽기·목록 조회 계수를 확인합니다.
- `tests/check_architecture.py`는 레이어 의존 방향과 파일시스템 호출 위치를 검사합니다.

파일 작업은 임시 디렉터리에서 실행합니다. 일부 PTY 권한 검사는 root 실행 시 생략합니다. 별도 네이티브 작업·회귀 검사에서는 root로 실행하면 자식 프로세스를 `nobody`로 낮춰 권한 오류를 검사합니다. 자세한 범위는 [사용 및 개발 참고서](docs/REFERENCE.md)를 참고하세요.

## Design Decisions

다음은 코드에 구현된 정책입니다.

- **표시와 실제 데이터 분리:** 정렬·파일 작업에는 원본 이름과 메타데이터를 사용합니다. 화면의 이스케이프나 읽기 쉬운 크기 문자열로 비교하지 않습니다. 이름 동률은 원본 바이트로 구분하며, 메인 정렬 설정은 검색 결과·선택기 순서에 적용하지 않습니다.
- **실패 시 상태 보존:** 새 디렉터리/검색 결과를 읽고 검증한 뒤 탐색 상태를 교체합니다. 실패한 새로고침은 기존 목록을 유지합니다.
- **제한된 미리보기 메모리:** 선택 파일별 reader 하나와 최근 512개 본문 조각을 캐시합니다. 조각당 최대 4,175바이트이고 페이지 요청은 최대 256조각입니다. 정렬만 바뀌면 세션을 유지하고 명시적 새로고침은 초기화합니다.
- **명시적인 불완전 결과:** 검색 누락, 한도, 취소, 치명적 오류를 구분합니다. 파일 작업의 `Result`는 부분 변경 여부와 완료 항목/바이트를 전달합니다.
- **재귀 작업의 링크 비추적:** 복사·삭제는 FD 기반 접근과 `O_NOFOLLOW`, 항목 식별 확인을 사용합니다. 링크 자체는 처리하지만 그 대상을 재귀 순회하지 않습니다. 파일시스템 스냅샷이나 트랜잭션을 제공하는 것은 아닙니다.

## Current Status

미리보기는 페이지 단위로 읽으며 파일 끝으로 즉시 건너뛰기 위해 전체 파일을 동기적으로 읽는 기능은 제공하지 않습니다. 미리보기의 좌우 방향키·Backspace는 목록 탐색을 실행하지 않습니다. 실행 파일도 내용만 미리 보며 외부 프로그램을 실행하지 않습니다.

현재 Linux/WSL용 POSIX 백엔드가 구현되어 있습니다. 다음은 확인 가능한 제한사항입니다.

- Windows 네이티브 백엔드, 파일 편집, 내용 검색, 정규식 검색, 설정 영구 저장, 휴지통/실행 취소, 패널 드래그 리사이즈는 구현되어 있지 않습니다.
- 이름 검색은 바이트 단위 `tolower()`를 사용하는 부분 문자열 비교입니다. 유니코드 정규화나 완전한 유니코드 대소문자 접기를 제공하지 않습니다. 심볼릭 링크 디렉터리 내부는 검색하지 않습니다.
- 검색 기본 한도는 방문 항목 100,000개, 결과 10,000개, 깊이 64입니다. 검색어 입력 버퍼는 256바이트(종료 문자 포함), 일반 UI 입력 버퍼는 4,096바이트입니다.
- 복사·삭제 재귀 작업은 깊이 64에서 중단합니다. 교차 파일시스템 이동과 이동 호출 중 취소는 지원하지 않습니다.
- 미리보기는 첫 4 KiB에 NUL이 있으면 바이너리로 분류합니다. 긴 줄은 조각으로 나누고 탭은 공백으로 바꿔 표시합니다. 파일 감시기나 유휴 타이머가 없으며 메타데이터 점검은 화면 갱신/뷰포트 변경에 따라 수행합니다.
- 취소는 협력 방식입니다. 느린 파일시스템 호출이 반환하기 전에는 즉시 취소하거나 화면을 갱신할 수 없습니다.

별도 로드맵이나 출시 일정은 이 README에서 가정하지 않습니다. 상세 정책과 포팅 경계는 [REFERENCE.md](docs/REFERENCE.md)에 있습니다.
