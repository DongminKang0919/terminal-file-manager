# tfile

C11과 ncursesw로 만든 **Linux/WSL용 터미널 파일 관리자**입니다. 키보드와 마우스로 디렉터리를 탐색하고, 검색·마킹·복사·이동·영구 삭제를 수행합니다. 텍스트 미리보기는 기본 제공하며 이미지와 PDF 미리보기는 선택 도구를 사용합니다.

![tfile 실행 화면: 파일 목록과 텍스트 미리보기](docs/images/tfile-main.png)

위 화면은 이전 버전에서 실제로 확보한 기록입니다. 최신 표시의 [PTY 셀 전후 비교](docs/UI_UX_COMPARISON.md)는 그래픽 터미널 스크린샷과 구분합니다.

## 빌드하고 실행하기

필수 의존성은 **C11 컴파일러, make, ncursesw 개발 라이브러리**입니다. 실행에는 대화형 터미널과 유효한 `TERM`/terminfo가 필요하며 UTF-8 로캘을 권장합니다. Python 3는 검사 도구용으로, 일반 실행에는 필요하지 않습니다.

Ubuntu의 패키지 설치 예시는 다음과 같습니다.

```sh
sudo apt update
sudo apt install build-essential libncurses-dev
make
./tfile
# 또는 시작 디렉터리 지정
./tfile /path/to/directory
```

빌드 결과는 저장소의 `tfile` 실행 파일입니다. `make install`이나 시스템 설치 단계는 제공하지 않습니다. 일반 실행에는 `TFILE_*` 환경변수 설정이나 이미지 진단 사전 실행이 필요하지 않습니다. 입출력 리다이렉션과 `TERM`이 없거나 `dumb`인 실행은 이유를 출력하고 종료합니다. SSH에서도 터미널 세션으로 실행하세요.

최소 화면은 **50열 × 9행**, 권장 화면은 **100열 × 24행**입니다. 더 작은 화면에서는 크기 안내를 표시하고 미디어 작업을 정리합니다. 넓혀서 계속 사용할 수 있습니다. 현재 확인한 환경은 Ubuntu 24.04의 비 root 사용자와 자동 PTY 검사이며, 모든 Linux 배포판·WSL·그래픽 터미널에서 검증한 것은 아닙니다.

## 첫 파일 작업

1. 방향키 또는 클릭으로 커서를 이동합니다. `Enter`/더블클릭으로 디렉터리를 열고 `Backspace`로 상위 디렉터리로 이동합니다. `[`/`]` 또는 `Alt+←`/`Alt+→`로 이전·다음 방문 위치로 돌아갑니다.
2. `Ctrl+F`는 현재 목록 빠른 찾기, `F3` 또는 `/`는 하위 디렉터리 이름 검색입니다. 결과에서 `Enter`로 열고 `[`로 이전 작업 위치에 돌아갑니다. 검색 창의 `Esc`는 닫기/진행 중 취소입니다.
3. `Space`로 작업할 항목을 마킹합니다. **`>`는 커서**, **`*`는 마킹**, 하단 **Marked**는 작업 대상 수입니다. 마킹이 없으면 커서 항목 하나가 대상입니다. 다른 디렉터리로 이동하면 그 목록의 마킹은 해제됩니다.
4. `F9` → **View: Left + Right files**로 두 목록을 열고 `Tab` 또는 클릭으로 활성 목록을 바꿉니다. 원본 목록에서 `F5` 복사 / `F6` 이동을 선택하면 반대 목록의 현재 디렉터리를 목적지로 제안합니다. 대상과 목적지를 확인하고 **Copy now / Move now**를 명시적으로 실행합니다.
5. `F2`로 파일 또는 디렉터리를 생성합니다. `F8`/`Delete`는 영구 삭제 확인이며 기본 선택은 **Cancel**입니다. 내용까지 삭제할 대상인지 확인한 뒤 Delete를 선택합니다.
6. 작업 결과는 하단 알림, 상세는 `!` 또는 상태 영역 클릭으로 확인합니다. `z`는 알림만 닫으며 상세를 보존합니다. `q`/`F10`으로 종료합니다.

처음 연습할 때는 실제 파일 대신 임시 디렉터리를 사용하세요.

```sh
playground=$(mktemp -d /tmp/tfile-play.XXXXXX)
mkdir "$playground/source" "$playground/destination"
printf 'Hello tfile\n' > "$playground/source/example.txt"
./tfile "$playground"
```

메인 상단에는 명령과 현재 경로, 패널에는 항목과 속성, 하단에는 상태 요약·작업 알림·현재 초점의 단축키를 표시합니다. **Shown**은 표시 항목 수, **Dotfiles: on/off**는 숨김 파일 표시 설정입니다. `F1`/`?`는 도움말, `F9`/`m`은 전체 메뉴입니다.

## 미리보기와 옵션

기본 화면은 **파일 목록 + 미리보기**입니다. 파일을 선택하면 텍스트·빈 파일·디렉터리·미지원 상태를 표시합니다. 스크롤할 내용이 있는 경우에만 `Tab`이나 클릭으로 미리보기에 초점을 옮깁니다. 미리보기 초점에서 방향키·페이지 키·휠로 스크롤하고 `Esc`로 목록에 돌아옵니다. 이미지처럼 별도 조작이 없는 미리보기는 목록 초점을 유지합니다. 이중 목록의 `Tab` 전환은 항상 유지합니다.

이미지/PDF는 **선택 의존성**입니다. 도구가 없어도 탐색·텍스트 미리보기·파일 작업은 사용할 수 있습니다.

| 선택 도구/조건 | 가능한 미리보기 |
| --- | --- |
| Sixel 터미널 + ImageMagick의 `magick` 또는 `convert` (SIXEL coder 포함) | PNG/JPEG 이미지 |
| 위 조건 + Poppler의 `pdftoppm` | PDF 첫 페이지 이미지 |
| Poppler의 `pdftotext` | 이미지 표시가 불가능할 때 PDF 첫 페이지 텍스트 |

Ubuntu에서 선택 도구를 설치하려면 다음 명령을 사용합니다.

```sh
sudo apt install imagemagick poppler-utils
```

기본 **Auto**는 필요할 때 터미널의 Sixel 지원과 셀 픽셀 크기를 자동 조회합니다. **도구 누락**, **터미널 무응답/미지원**, **Off**, **변환 실패**는 다른 안내로 표시합니다. 지원을 확인하지 못해도 파일 관리는 계속됩니다. `F7` → **Image display setup**은 감지 실패 복구와 실제 표시·지우기 확인용 진단입니다. 터미널의 지원 응답은 실제 픽셀 표시/잔상 검증을 대신하지 않습니다.

이미지와 PDF 첫 페이지는 메타데이터 아래 콘텐츠 영역의 중앙에 원본 비율을 유지한 Fit 방식으로 표시합니다. 작은 래스터는 확대하지 않습니다. 출력 최대 **1536×1152 픽셀 / 2 MiB**, 입력 **64 MiB**, 변환 **8초**와 메모리 제한을 유지합니다. PDF 페이지 이동·확대/축소·tmux/screen 그래픽 passthrough는 제공하지 않습니다. 자세한 감지·제한·복구는 [상세 사용 안내](docs/USER_GUIDE.md#선택적-이미지pdf-미리보기-1단계)를 참고하세요.

`F7`에서 숨김 표시·정렬·화면 모드·휠 이동량·이미지 Auto/Off를 변경합니다. **Save current settings as startup defaults**를 선택해야 다음 실행에 저장되며 종료 시 자동 저장하지 않습니다. 기본 저장 위치는 `$XDG_CONFIG_HOME/tfile/settings.conf` 또는 `$HOME/.config/tfile/settings.conf`입니다. 시작 경로·마킹·방문 기록·터미널 지원/셀 크기는 저장하지 않습니다. 잘못된 기존 설정은 경고하고 기본값으로 실행하며 사용자 확인 없이 덮어쓰지 않습니다.

팝업에서는 `Tab`/`Shift+Tab`으로 조작 요소를 이동하고 `Enter`로 실행, `Esc`/닫기로 취소합니다. 목록 탐색과 진행 중 취소는 창의 안내를 따르세요. 리사이즈하면 열린 팝업은 닫히고 진행 작업에는 취소를 요청합니다. 입력 검증 오류는 입력을 유지하며 수정할 위치로 돌아갑니다.

## 파일 작업의 안전 정책과 제한

- 삭제는 **휴지통 없는 영구 삭제**입니다. 디렉터리 내용도 삭제하며 링크 대상은 따라가지 않습니다.
- 기존 파일을 덮어쓰거나 디렉터리를 병합하지 않습니다. 자동 이름 변경·자기 내부로의 전송도 제공하지 않습니다.
- 이동은 같은 파일시스템에서만 지원합니다. 교차 파일시스템 이동은 오류이며 복사 후 삭제로 대체하지 않습니다.
- 일괄 작업은 현재 목록 순서로 처리하고 첫 실패/취소에서 중단합니다. 나머지는 미실행입니다. 성공 항목은 마킹을 해제하고 실패·취소·미실행 항목은 목록에 남아 있으면 마킹을 유지합니다.
- 취소/부분 실패는 이미 완료한 변경을 되돌리지 않습니다. 잔여물을 자동 삭제하지 않으므로 `!`에서 대상별 결과를 확인하세요. 작업 성공과 목록 갱신 실패는 별도로 기록합니다.

## 자세한 안내와 검증

```sh
make -j4 check
```

전체 검사는 임시 HOME/XDG와 개발용 `TFILE_*` 변수를 제거한 환경에서 실행합니다. 파일 작업 검사는 임시 디렉터리를 사용합니다. 물리 터미널의 폰트·색·Sixel 표시/잔상은 자동 PTY 결과와 구분하며, LSan의 알려진 ptrace 환경 제약은 누수 검사 통과로 기록하지 않습니다.
