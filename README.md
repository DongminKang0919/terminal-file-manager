# tfile

**마우스와 키보드로 사용하는 터미널 파일 관리자.**

C와 ncursesw로 만들었습니다. 왼쪽에서 파일을 탐색하고 오른쪽에서 내용을 미리 보며, 터미널 안에서 검색·복사·이동·이름 변경을 할 수 있습니다. 메뉴와 팝업을 마우스로 조작할 수 있어 단축키를 외우지 않고도 시작할 수 있습니다.

## 주요 기능

- **파일 탐색** — 클릭으로 선택, 더블클릭으로 디렉터리 열기, 이전·다음 방문 위치로 이동.
- **텍스트 미리보기** — 파일 정보와 본문을 옆 패널에서 확인하고, 휠로 스크롤.
- **이름 검색** — 현재 디렉터리 아래의 숨김 항목까지 검색하고 결과 위치로 이동.
- **파일 작업** — 파일·디렉터리 생성, 복사, 이동, 이름 변경, 삭제. 복사·이동 대상은 선택기로 지정.
- **진행 표시와 취소** — 복사·삭제 중 현재 경로와 완료 항목 수를 확인하고 취소 요청.
- **목록 설정** — 이름·크기·수정일·종류별 정렬, 숨김 파일과 미리보기 표시 전환.
- **한글 입력과 표시** — UTF-8 파일명과 경로를 표시하고 팝업에서 한글 입력.

## 시작하기

### 필요한 환경

- **Linux 또는 WSL** — 현재 Windows 네이티브 빌드는 지원하지 않습니다.
- C11 컴파일러, `make`, **ncursesw 개발 라이브러리**
- UTF-8 로캘을 사용하는 터미널. 마우스 조작은 터미널의 마우스 입력 지원이 필요합니다.

터미널 크기는 **100열 × 24행 이상**을 권장합니다. 최소 지원 크기는 50열 × 9행입니다.

### 빌드와 실행

저장소를 내려받은 뒤 프로젝트 디렉터리에서 실행하세요.

```sh
make
./tfile
```

시작할 디렉터리를 지정할 수도 있습니다.

```sh
./tfile /path/to/directory
```

## 기본 사용법

1. 파일을 클릭하면 오른쪽에 정보와 텍스트 미리보기가 표시됩니다.
2. 디렉터리를 더블클릭하거나 `Enter`로 엽니다. **Parent** 또는 `Backspace`로 상위 디렉터리로 이동합니다.
3. 항목을 선택한 뒤 상단 메뉴에서 복사·이동·삭제를 실행합니다. **F9 Menu**에서 전체 명령을 확인할 수 있습니다.
4. **F7 Options**에서 정렬, 숨김 파일 표시, 미리보기, 휠 이동량을 바꿉니다.

왼쪽 목록 위의 휠은 선택을 이동하고, 오른쪽 미리보기 위의 휠은 본문을 스크롤합니다. 팝업은 `Esc` 또는 **[ x ]**로 닫습니다.

### 자주 쓰는 키

| 키 | 동작 |
| --- | --- |
| `↑` / `↓`, `k` / `j` | 선택 이동 |
| `Enter` / `→` | 디렉터리 열기 |
| `Backspace` / `←` | 상위 디렉터리로 이동 |
| `Alt+←` / `Alt+→`, `[` / `]` | 이전 / 다음 방문 위치 |
| `F2` | 파일·디렉터리 생성 |
| `F3`, `/` | 이름 검색 |
| `F5` | 복사 |
| `F6` | 이동·이름 변경 |
| `F8`, `Delete` | 삭제 확인 |
| `F7` | 옵션 |
| `F9`, `m` | 전체 메뉴 |
| `F1`, `?` | 도움말 |
| `r` | 새로고침 |
| `q`, `F10` | 종료 |

## 사용 전에 알아둘 점

- **삭제는 휴지통을 거치지 않으며 실행 취소할 수 없습니다.** 디렉터리를 삭제하면 내부 항목도 삭제됩니다. 실행 전 확인창이 표시됩니다.
- 복사·이동은 **기존 대상을 덮어쓰지 않습니다.** 이동은 같은 파일시스템 안에서만 지원합니다.
- **취소는 이미 수행한 작업을 되돌리지 않습니다.** 복사 실패·취소 시 일부 파일이나 디렉터리가 남을 수 있고, 이미 삭제한 항목은 복구되지 않습니다.
- 검색은 **파일 이름**을 대상으로 하며 파일 내용은 검색하지 않습니다. 텍스트 미리보기를 제공하지만 편집기는 포함하지 않습니다.
- 옵션은 현재 실행에만 적용됩니다. 파일 목록을 갱신하려면 `r`을 누르세요.

## 개발

UI, 핵심 로직, 운영체제별 파일 접근을 분리한 구조입니다. 현재 플랫폼 구현은 POSIX 하나이며, 핵심 로직은 ncurses에 의존하지 않습니다.

```text
.
├── src/
│   ├── model.h, model.c   공통 데이터와 오류 모델
│   ├── core/              탐색·정렬·검색·미리보기·파일 작업
│   ├── platform/          파일시스템 접근과 POSIX 구현
│   └── ui/                ncurses 화면·입력·팝업
└── tests/                핵심 로직 및 터미널 통합 테스트
```

테스트에는 빌드 도구 외에 **Python 3**가 필요합니다.

```sh
make check-core  # 핵심 로직·POSIX 구현·의존성 검사
make check       # 위 검사 + UI 및 실제 터미널 입력(PTY) 테스트
```

테스트는 임시 디렉터리에서 파일 작업을 수행합니다. 파일 작업의 실패·취소, 검색, 정렬, 유니코드 표시, 미리보기, 마우스·키보드 입력 등을 검사합니다.
