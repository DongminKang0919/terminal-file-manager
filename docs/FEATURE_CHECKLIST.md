# tfile 기능 작업 체크리스트

2026-11-18 논의 기준. 체크는 구현과 항목별 검증을 마친 뒤 갱신한다.

## P0 — 교차 파일시스템 이동의 원본 보호 설계

- [x] 원래 경로 대신 격리된 원본을 기준으로 작업하는 후보와 열린 쓰기 FD의 한계를 문서화했다. [교차 파일시스템 이동 설계](CROSS_FILESYSTEM_MOVE_DESIGN_2026-10-09.md)
- [ ] 원본 부모 FD를 고정하고 같은 파일시스템의 전용 디렉터리에 덮어쓰기 없이 격리하는 절차를 확정한다. 열린 원본 FD와 격리 항목의 device·inode·종류를 비교하고, 경로 교체 및 복원 충돌 때의 동작을 정한다.
- [ ] 일반 파일의 완료 의미를 결정한다. 제안은 목적지 복사 확정 후 원본을 소스 파일시스템의 휴지통에 보관하는 방식이다. 열린 쓰기 FD와 하드 링크를 통한 변경, 지원 파일시스템, 휴지통 사용 불가 시 거부 정책을 함께 정한다.
- [ ] 목적지 내용 검증과 파일·부모 디렉터리 동기화, 권한·시간 등 메타데이터 보존 범위, 취소와 크래시 후 복구, 남은 경로 표시를 확정한다.

## P1 — 원본 복구와 교차 파일시스템 이동

- [ ] **앱 내 휴지통 복원.** 휴지통 목록에서 항목 하나를 골라 원래 위치에 복원한다. 목적지 이름 충돌이나 부모 경로 부재 시 항목을 보존하고 이유를 표시한다. 홈 휴지통과 파일시스템별 휴지통의 지원 범위를 명시한다. 손상된 메타데이터, 경로 이탈, 심볼릭 링크, 복원 실패 시 원본 보존을 검증한다.
- [ ] **교차 파일시스템 이동 첫 버전.** P0의 정책을 확정한 뒤 일반 파일 하나로 시작한다. 휴지통 보관 방식으로 결정되면 앱 내 복원을 먼저 완료한다. 기존 같은 파일시스템 이동과 이름 충돌 처리를 유지하고, 성공·부분 처리·취소·복구 가능한 원본의 위치를 최근 작업 결과에 표시한다.
- [ ] **실제 두 파일시스템 검증.** 서로 다른 `st_dev`의 마운트에서 성공, 이름 충돌, 원본 경로 교체, 동시 쓰기, 취소, 동기화 실패, 크래시 후 복구를 확인한다. 휴지통을 사용할 수 없는 경우 원본이 남는지 확인한다.
- [ ] **데스크톱 휴지통 호환 검증.** 전용 임시 파일로 데스크톱 파일 관리자에서 tfile이 보낸 항목의 복원을 확인한다. [기존 수동 검증 목록](FEATURE_PROGRESS_2026-10-09.md#6단계-보류)
- [ ] **README 첫 화면 교체.** 현재 버전의 실제 터미널에서 마킹 대상, 활성 패널 초점, 하단 조작 안내가 보이는 화면을 캡처하고 설명을 갱신한다. 앞선 파일 작업과 병행할 수 있다.

## P2 — 탐색과 전송 편의

- [ ] **충돌 시 새 이름으로 계속.** 일괄 복사·이동에서 충돌한 항목만 새 이름을 지정해 진행하고, 다시 충돌해도 기존 파일을 보존한다.
- [ ] **충돌 시 자동 이름 변경.** 사용자가 선택할 수 있는 충돌 처리 옵션으로 이름 생성 규칙을 정하고, 동시 생성으로 후보 이름이 선점된 경우를 검증한다.
- [ ] **텍스트 미리보기 안에서 검색.** 다음·이전 일치 위치로 이동하고, 일치 없음과 검색 취소 후 위치를 확인한다.
- [ ] **PDF 페이지 이동.** 첫 페이지 전용 미리보기를 확장하고, 페이지 경계와 빠른 연속 전환 시 이전 렌더 취소를 검증한다.

## P3 — 별도 정책이나 지원 환경이 필요한 기능

- [ ] **덮어쓰기.** 파일 유형별 충돌 정책과 명시적 확인을 설계하고, 대상 교체 경쟁과 실패 시 기존 파일 보존을 검증한다.
- [ ] **폴더 병합.** 하위 항목별 충돌 정책을 정하고, 부분 완료와 취소 결과를 확인한다.
- [ ] **부분 실패 후 자동 정리.** 이번 작업에서 만들었음을 확인할 수 있는 항목만 정리하는 조건을 설계한다.
- [ ] **부분 실패 후 재시도.** 완료·미완료 항목을 구별하고, 반복 실행과 동시 경로 변경에 대한 정책을 정한다.
- [ ] **교차 파일시스템 이동 범위 확대.** 일반 파일 첫 버전 검증 후 디렉터리의 항목 추가·삭제·교체, 열린 쓰기 FD, 하드 링크, 하위 마운트를 별도로 설계한다.
- [ ] **PDF 확대·축소.** 페이지 이동 이후 렌더 크기 한도와 패널 안에서의 이동 방식을 정한다.
- [ ] **PDF OCR.** 스캔 페이지에서 사용할 선택 의존성과 처리 한도, 실패 시 동작을 정한다.
- [ ] **tmux 그래픽 passthrough.** 지원 환경을 정하고 실제 터미널에서 표시와 이미지 지우기를 확인한다.
- [ ] **screen 그래픽 passthrough.** 지원 가능 여부를 확인하고, 지원 시 실제 터미널에서 표시와 이미지 지우기를 검증한다.
